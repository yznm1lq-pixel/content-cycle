# دورة المحتوى | Content Cycle

برنامج بسيط لإدارة رحلة إنتاج المحتوى، من تسجيل الفكرة إلى التخطيط والكتابة والمراجعة والتصميم والاعتماد والنشر والأرشفة.

## فكرة المشروع

تُعامل عملية إنتاج المحتوى كدورة تشغيلية لها مراحل واضحة. يساعد البرنامج على تسجيل عناصر المحتوى، ومتابعة المرحلة الحالية لكل عنصر، واستخراج مؤشرات مختصرة عن تدفق العمل.

يرتبط المشروع بمفاهيم الهندسة الصناعية، ومنها:
- **تدفق العمل (Workflow):** تنظيم انتقال المحتوى بين مراحل الإنتاج.
- **العمل قيد التنفيذ (WIP):** معرفة عدد العناصر التي لم تصل إلى النشر بعد.
- **زمن الدورة (Cycle Time):** حساب متوسط المدة من تسجيل المحتوى حتى وصوله إلى مرحلة النشر.
- **الازدحام:** إظهار المرحلة التي يوجد فيها أكبر عدد من عناصر المحتوى الحالية. هذا مؤشر لحظي للازدحام، وليس إثباتاً نهائياً لعنق الزجاجة.

## مراحل دورة المحتوى

1. الفكرة
2. التخطيط
3. الكتابة
4. المراجعة
5. التصميم
6. الاعتماد
7. النشر
8. الأرشفة

## الوظائف

- إضافة محتوى جديد مع عنوانه ونوعه.
- عرض جميع عناصر المحتوى ومراحلها الحالية.
- تحديث مرحلة أي عنصر.
- حفظ البيانات تلقائياً في ملف `contents.json`.
- عرض تقرير يتضمن إجمالي المحتوى، وقيد الإنتاج، والمنشور أو المؤرشف، ونسبة الوصول إلى النشر.
- حساب متوسط زمن الدورة للعناصر التي وصلت إلى النشر.

## متطلبات التشغيل

- Python 3.7 أو أحدث.
- لا يحتاج المشروع إلى تثبيت مكتبات خارجية؛ فهو يستخدم مكتبات Python القياسية.

## طريقة التشغيل

1. نزّل المستودع أو استنسخه من GitHub.
2. افتح الطرفية داخل مجلد المشروع.
3. شغّل الأمر:

```bash
python content_cycle.py
```

في Windows يمكن استخدام:

```bash
py content_cycle.py
```

سيُنشئ البرنامج ملف `contents.json` تلقائياً عند حفظ أول عنصر محتوى إذا لم يكن موجوداً.

## مثال تشغيل

المثال التالي يوضح إضافة عنصر محتوى ثم عرض تقرير الإنتاج. المخرجات معروضة كما تظهر في البرنامج:

```text
===== دورة المحتوى | Content Cycle =====
1. إضافة محتوى جديد
2. عرض المحتوى
3. تحديث مرحلة الإنتاج
4. تقرير الإنتاج
5. خروج
اختر العملية: 1

--- إضافة محتوى جديد ---
عنوان المحتوى: إطلاق مبادرة جديدة
نوع المحتوى (مقال/منشور/تقرير...): تقرير
تمت إضافة المحتوى بنجاح. رقم المحتوى: 1

===== دورة المحتوى | Content Cycle =====
1. إضافة محتوى جديد
2. عرض المحتوى
3. تحديث مرحلة الإنتاج
4. تقرير الإنتاج
5. خروج
اختر العملية: 4

========== تقرير دورة المحتوى ==========
إجمالي المحتويات: 1
قيد الإنتاج: 1
منشور أو مؤرشف: 0
نسبة الوصول إلى النشر: 0.0%
أعلى مرحلة من حيث عدد المحتويات الحالية: الفكرة (1)
ملاحظة: هذا مؤشر ازدحام لحظي، وليس قياساً نهائياً لعنق الزجاجة.
========================================
```

## الملفات

- `content_cycle.py`: كود البرنامج.
- `contents.json`: ملف تخزين بيانات المحتوى، ويُنشأ تلقائياً عند أول عملية حفظ.

## ملاحظة

هذا المشروع نموذج مبسط لإدارة دورة إنتاج المحتوى، ويمكن تطويره لاحقاً بإضافة سجل تفصيلي لمدة كل مرحلة أو واجهة رسومية. المؤشرات الحالية وصفية ومناسبة لمتابعة أولية لسير العمل.

## التحقق من صحة النتائج – المثال الثاني

للتحقق من صحة الحسابات، نختبر البرنامج ببيانات معروفة مسبقاً:

**بيانات الاختبار:**
- المحتوى الأول: «إطلاق مبادرة جديدة» – المرحلة الحالية: الكتابة.
- المحتوى الثاني: «إعداد تقرير الأداء» – المرحلة الحالية: الكتابة.

**الحساب اليدوي للنتائج المتوقعة:**
- إجمالي المحتويات = 2.
- قيد الإنتاج = 2؛ لأن العنصرين لم يصلا إلى النشر أو الأرشفة.
- المنشور أو المؤرشف = 0.
- نسبة الوصول إلى النشر = (0 ÷ 2) × 100 = **0%**.
- أعلى مرحلة من حيث عدد المحتويات الحالية = **الكتابة (2)**؛ لأن العنصرين موجودان في هذه المرحلة.

**ناتج البرنامج المتوقع والفعلي عند اختيار «تقرير الإنتاج» بعد إدخال العنصرين ونقل كليهما إلى مرحلة الكتابة:**

```text
========== تقرير دورة المحتوى ==========
إجمالي المحتويات: 2
قيد الإنتاج: 2
منشور أو مؤرشف: 0
نسبة الوصول إلى النشر: 0.0%
أعلى مرحلة من حيث عدد المحتويات الحالية: الكتابة (2)
ملاحظة: هذا مؤشر ازدحام لحظي، وليس قياساً نهائياً لعنق الزجاجة.
========================================
```

تتطابق النتائج الفعلية مع الحساب اليدوي. ولم يظهر متوسط زمن الدورة في هذا الاختبار لعدم وجود عناصر منشورة أو مؤرشفة؛ إذ يحسب البرنامج هذا المتوسط للعناصر التي وصلت إلى إحدى هاتين المرحلتين فقط.
